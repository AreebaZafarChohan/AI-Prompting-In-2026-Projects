## 📂 Projects & Working Breakdown

### 🐍 Project 1: Snake Battle (3-Version Evolution)
- **Directory:** [`Project1-Snake-Battle/`](./Project1-Snake-Battle/)
- **Documentation:** [`Project1-Snake-Battle/README.md`](./Project1-Snake-Battle/README.md)
- **Concept:** Demonstrates the evolution of an arcade snake game across three different architectural paradigms:
  1. **Version 1 (`version1/`)**: 4 procedural environmental realms (Forest, Desert, Ocean, Space) with distinct tactical combat mechanics, essence collection, and 5 distinct AI personalities.
  2. **Version 2 (`version2/`)**: High-energy arcade score chaser with frenzy fruit floods, power-up systems (Magnets, Multipliers, Shields), dynamic combo meters, and touch/D-pad controls.
  3. **Version 3 (`version3/`)**: Agentic step-by-step curriculum standard featuring multi-snake combat, live bot respawns, corpse fruit transformation, and live leaderboard tracking.

### 👾 Project 2: Whack-a-Mole — Cyberpunk Arcade
- **Directory:** [`Project2-Whack-a-Mole/`](./Project2-Whack-a-Mole/)
- **Documentation:** [`Project2-Whack-a-Mole/README.md`](./Project2-Whack-a-Mole/README.md)
- **Live URL:** [https://ai-prompting-in-2026-projects-y6nq.vercel.app/](https://ai-prompting-in-2026-projects-y6nq.vercel.app/)
- **Concept & Working:**
  - **3 Live Swappable Themes**: *Cyberpunk Arcade* (neon aliens & warp portals), *Classic Meadow* (cute moles & dirt mounds), and *Haunted Graveyard* (skeletal ghosts & stone crypts).
  - **4 Progressive Difficulty Levels**: Controlled speed curves moving from Easy (~2.5s stay time) up to Frenzy (~0.72s stay time with multi-spawns).
  - **Dynamic Combo Multiplier Engine**: Consecutive hit streaks scaling points from 1x to 5x with screen shakes, squash animations, and particle explosions.
  - **Procedural Zero-Asset Sound Engine**: Built entirely with Web Audio API for hit crunches, miss wobbles, level-up chords, and fanfare.
  - **Interactive Analytics**: Hits-per-minute (HPM) tracker, golden bonus targets (+3 base points), and persistent local high scores.

## 🛠️ Key Agentic Development Methodologies

Across all projects, development followed a rigorous agentic loop:
1. **Separation of Ideation and Implementation:** Establishing themes and design tokens before code generation.
2. **Context Engineering:** Supplying structured requirements, input/output contracts, and strict scope limits.
3. **Continuous Playtesting & Feedback Loops:** Identifying mechanical friction during real runtime testing and issuing targeted polish prompts.
4. **Self-Scoring Rubrics:** Evaluating code quality, visual clarity, game feel, and UX against objective standards.
5. **Zero-Dependency Architecture:** Clean, maintainable, lightweight vanilla web technologies (HTML5, CSS3, JavaScript ES6+, Web Audio API, SVG).
