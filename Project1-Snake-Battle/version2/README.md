# 🐍 Snake Fruit Frenzy (Version 2)

An enhanced, vibrant arcade snake game built with HTML5 Canvas, responsive CSS, and Web Audio API synthesized sound effects.

## 🌟 Highlights & Features

1. **Juicy Fruit Ball Variety:**
   - 🍎 **Strawberry:** +10 pts, +1 length
   - 🍊 **Orange:** +25 pts, +1 length
   - 🍇 **Grapes:** +50 pts, +2 length
   - 🍉 **Watermelon:** +80 pts, +2 length
   - ⭐ **Star Fruit:** +150 pts, +3 length
   - 💎 **Dragon Orb (Rare):** +300 pts, +4 length
   - 🌈 **Frenzy Orb (Ultra Rare):** +500 pts, +5 length & triggers instant Fruit Frenzy!

2. **Combo Multipliers & Fruit Frenzy Mode:**
   - Eat fruit balls quickly before the combo timer runs out to build up to 5x multiplier combos.
   - Reaching a **5x Combo** triggers **Fruit Frenzy**, flooding the arena with extra fruits and granting a 1.5x score booster.

3. **Power-ups:**
   - 🧲 **Magnet:** Pulls nearby fruit balls directly toward the snake's head.
   - ⚡ **Speed Surge:** Gives a rush of speed and point bonus.
   - 🛡️ **Energy Shield:** Protects the snake from one fatal collision against a wall or obstacle.
   - ✂️ **Tail Trim:** Instantly cuts 25% of tail length for easier maneuvering.
   - ✖️2 **2x Score Multiplier:** Doubles all score points earned.

4. **Multiple Game Modes & Customizations:**
   - **Classic Arena:** Solid boundary walls.
   - **Cosmic Wrap:** Pass through boundaries seamlessly.
   - **Crystal Maze:** Dynamic crystal barriers spawn inside the arena.
   - **6 Glowing Snake Skins:** Emerald Glow, Cyber Neon, Cosmic Violet, Solar Flare, Ruby Blaze, and Candy Pop.
   - **4 Movement Speeds:** Casual, Normal, Fast, and Insane.

5. **Controls:**
   - **Desktop:** `W`, `A`, `S`, `D` or Arrow keys `↑`, `←`, `↓`, `→`
   - **Pause:** `Space` or Pause icon button
   - **Mobile / Touch:** Swipe gestures or on-screen D-Pad
