Part 1 • Studied Curriculum

How AI Knows Things

Understanding model memory, retrieval mechanics, and the boundaries of pre-trained knowledge.

  • Novice vs. Power User: Transitioning from simple one-liners to structured briefings with context, goals, and strict constraints.
  • Pretrained Knowledge Limits: Distinguishing training density from factual confidence; avoiding hallucinations on private or obscure data.
  • The 3 Retrieval Modes: Directing models to internal parametric memory, web grounding, or multi-source deep research.
Part 2 • Studied Curriculum

Talking to AI Well

Context stack architecture, extended reasoning, and iterative refinement techniques.

  • 6-Layer Context Stack: Managing system instructions, memory, tool definitions, chat logs, and workspace files without context degradation.
  • Extended Reasoning: Activating built-in deliberate thinking for high-complexity decisions and algorithmic trade-offs.
  • Neutralizing Sycophancy: Counteracting model flattery using neutral phrasing, rubric-based scoring, and permission to say "I don't know".
  • Brainstorm-Iterate Loop: Staged generation (context → options → critique → revision → finalized draft).
Part 3 • Studied Curriculum

Beyond Text

Multimodal inputs, artifacts, single-prompt apps, and programmatic data validation.

  • Multimodal Inputs: Processing visual diagrams, interface mockups, and transcribed voice briefings.
  • Single-Prompt App Generation: Specifying inputs, state, and visual UI to build interactive single-screen web utilities and games.
  • Code-Driven Data Analysis: Enforcing code-execution verification (Python/JS scripts) rather than uncalculated statistical estimations.
Part 4 • Studied Curriculum

Safety, Agents & Tool Selection

Agent safety ladders, token economics, and cross-model evaluation.

  • Desktop Agents & Access: Operating file-aware agents using staged permission ladders (plan-first execution, scoped permissions).
  • Media Economics: Factoring token costs, latency, and capability trade-offs into tool selection.
  • Cross-Model Evaluation: Utilizing competing model providers as objective peer-reviewers for critical deliverables.
